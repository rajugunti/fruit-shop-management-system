# Fruit Shop Management System

A console-based Fruit Shop Management System developed using Python and MySQL.

## Features

- Owner and User roles
- Inventory management
- Add, remove and update fruits
- Stock management
- Shopping cart
- Add, remove and modify cart items
- Billing system
- User registration
- Basic profit calculation
- MySQL database connectivity

## Technologies Used

- Python
- MySQL
- SQL
- MySQL Connector/Python
